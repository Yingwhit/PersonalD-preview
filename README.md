# 拯救ADHD · 浏览器交互预览

可交互的独立网页原型，包含事项、物品展开、计时、日历和购物清单，用于讨论界面与操作。

- 使用示例数据，操作记录保存在各自浏览器的 localStorage 中。
- 与手机 App 数据独立；网页操作不会修改手机记录。
- 网页文件更新部署后，会自动检查更新；已保存记录保留，打开的表单会延后刷新。
- Android 的后台计时、通知和权限行为仍需在实际 App 中验证。

## GitHub Pages

仓库 Settings → Pages → Build and deployment：选择 Deploy from a branch，分支 `main`，目录 `/ (root)`。

## 本地运行

```bash
python3 -m http.server 4173
```

在同一台电脑浏览器打开 `http://127.0.0.1:4173`。

`index.html` 为包含 CSS 和 JavaScript 的单文件网页，由独立预览源码生成。

## 本轮预览更新

- 顶部切换 PC／小米 15 Ultra，手机以 412×916 CSS 视口模拟 1440×3200 屏幕比例；可以适应窗口或按 100% 查看。真实逻辑尺寸受显示缩放和浏览器设置影响。
- 首个 Tab 为“做点什么”，查看逾期、今天、本周及无日期事项；可选择“本周内，但暂不定哪天”。
- 事项按家务、宠物、想法等分类浏览，可自定义和修改分类。想法是普通事项分类，快速记录时默认无日期。
- 按预计用时、当前精力和名称搜索组合筛选，也可用本地规则“帮我挑一件”。
- 保留已有预览记录；切换设备保留输入和计时，网页部署更新后自动检查版本。

本轮为浏览器预览更新，Android 安装包尚未同步。参考应用、采用的设计与后续建议见 [设计依据](RESEARCH.md)。
